Che cosa sono le Digital Humanities?

Le Digital Humanities usano strumenti digitali per studiare testi, archivi, immagini, dati culturali e collezioni.

Perché Python?

  • Sintassi leggibile
  • Molte librerie
  • Ottimo per testi e dati
  • Usato in ricerca e didattica

Che cos’è un programma?

Un programma è una sequenza di istruzioni che il computer esegue.


Input → Istruzioni → Output

Due ambienti di lavoro

Google Colab

Lavora online nel browser.

VS Code

Lavora sul computer locale.

Google Colab

  • Non richiede installazione locale
  • Si usa dal browser
  • Organizzato in celle
  • Utile per esercizi condivisi

Visual Studio Code

  • Editor per scrivere script
  • Utile per file e progetti
  • Richiede Python installato
  • Permette di lavorare in locale

Installare Python

  1. Scaricare Python da python.org
  2. Installare la versione recente
  3. Su Windows: selezionare “Add Python to PATH”
  4. Verificare dal terminale

Verificare Python


python --version

Terminale

Il terminale serve per eseguire comandi, installare librerie e lanciare script.


python nome_file.py

Primo file Python

Un file Python ha estensione .py.


lezione1.py

Il comando print()

print() mostra un risultato sullo schermo.


print("Ciao mondo")

Testo tra virgolette

Le stringhe di testo devono essere racchiuse tra virgolette.


print("Digital Humanities")

Stampare una citazione


print("Nel mezzo del cammin di nostra vita")

Più istruzioni


print("Titolo: Frankenstein")
print("Autrice: Mary Shelley")
print("Anno: 1818")

Commenti

I commenti spiegano il codice e non vengono eseguiti.


# Questo è un commento
print("Frankenstein")

Errore comune

Virgolette mancanti


print(Frankenstein)

Versione corretta

Stringa corretta


print("Frankenstein")
