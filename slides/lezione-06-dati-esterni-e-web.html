File TXT

Un file di testo contiene caratteri leggibili.


frankenstein.txt

Aprire un file


with open("frankenstein.txt", "r", encoding="utf-8") as file:
    testo = file.read()

print(testo)

Che cosa significa r?

r significa read: aprire il file in modalità lettura.

encoding

encoding="utf-8" aiuta Python a leggere correttamente accenti e caratteri speciali.

Percorsi dei file


cartella/file.txt
Documenti/corso/frankenstein.txt

Errore comune

FileNotFoundError

Python non trova il file nel percorso indicato.

Controllare la cartella corrente


import os

print(os.getcwd())
print(os.listdir())

Leggere solo una parte


with open("frankenstein.txt", "r", encoding="utf-8") as file:
    testo = file.read()

print(testo[:500])

Dati dal Web

Molte risorse DH sono online: Project Gutenberg, Wikisource, Wikipedia, archivi digitali.

URL

Un URL è l’indirizzo di una risorsa sul Web.


https://www.gutenberg.org/files/84/84-0.txt

requests

La libreria requests permette di scaricare contenuti dal Web.


import requests

url = "https://www.gutenberg.org/files/84/84-0.txt"
risposta = requests.get(url)

print(risposta.text[:500])

Workflow Web


URL → richiesta → risposta → testo

Salvare un testo scaricato


import requests

url = "https://www.gutenberg.org/files/84/84-0.txt"
testo = requests.get(url).text

with open("frankenstein.txt", "w", encoding="utf-8") as file:
    file.write(testo)

HTML

Le pagine web sono scritte in HTML, una struttura fatta di tag.


<h1>Mary Shelley</h1>
<p>Autrice di Frankenstein</p>

BeautifulSoup

BeautifulSoup serve per leggere ed esplorare HTML.


from bs4 import BeautifulSoup

html = "<h1>Mary Shelley</h1>"
soup = BeautifulSoup(html, "html.parser")
print(soup.h1.text)

Estrarre il titolo di una pagina


import requests
from bs4 import BeautifulSoup

url = "https://en.wikipedia.org/wiki/Mary_Shelley"
pagina = requests.get(url)
soup = BeautifulSoup(pagina.text, "html.parser")

print(soup.title.text)

Mini progetto

Scaricare un testo, salvarlo e mostrarne una parte.


import requests

url = "https://www.gutenberg.org/files/84/84-0.txt"
testo = requests.get(url).text

with open("frankenstein.txt", "w", encoding="utf-8") as file:
    file.write(testo)

print("Caratteri:", len(testo))
print(testo[:300])
