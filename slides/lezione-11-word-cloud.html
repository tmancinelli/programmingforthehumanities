☁️ Che cos’è una Word Cloud?

Una word cloud visualizza le parole più frequenti: più una parola è frequente, più appare grande.

Uso nelle DH

È utile per una prima esplorazione, ma non sostituisce l’interpretazione critica.

Installazione


pip install wordcloud matplotlib

Testo di esempio


testo = """
Victor studied science. The creature wanted love.
Science changed Victor and the creature.
"""

Generare la Word Cloud


from wordcloud import WordCloud
import matplotlib.pyplot as plt

wordcloud = WordCloud(width=800, height=400).generate(testo)
plt.imshow(wordcloud)
plt.axis("off")
plt.show()

Sfondo e dimensioni


wordcloud = WordCloud(
    width=1000,
    height=500,
    background_color="white"
).generate(testo)

Stopwords

Alcune parole sono frequenti ma poco informative.

Stopwords personalizzate


stopwords = {"the", "and", "of", "a"}
wordcloud = WordCloud(stopwords=stopwords).generate(testo)

Salvare immagine


wordcloud.to_file("wordcloud.png")

Word Cloud da file


with open("frankenstein.txt", "r", encoding="utf-8") as file:
    testo = file.read()

Controllare le frequenze


from collections import Counter
tokens = testo.lower().split()
conteggio = Counter(tokens)
print(conteggio.most_common(10))

HTML semplice


html = """
<h1>Word Cloud</h1>
<img src="wordcloud.png">
"""
with open("wordcloud.html", "w", encoding="utf-8") as f:
    f.write(html)

Domande interpretative

  • Quali parole emergono?
  • Sono temi o solo forme frequenti?
  • Cosa è stato escluso?

Limiti

  • non mostra contesto
  • non distingue significati
  • dipende dalla pulizia del testo
