🕸️ Che cos’è la Network Analysis?

Studia le relazioni tra entità: persone, luoghi, testi, concetti.

Nodi e archi

  • Nodi: entità
  • Archi: relazioni

Esempio DH

In un romanzo, i personaggi possono diventare nodi e le interazioni archi.

Installazione


pip install networkx matplotlib

Creare un grafo


import networkx as nx
G = nx.Graph()

Aggiungere un arco


G.add_edge("Victor", "Elizabeth")

Lista relazioni


relazioni = [
    ("Walton", "Victor"),
    ("Victor", "Creature"),
    ("Victor", "Elizabeth")
]

Ciclo sulle relazioni


for p1, p2 in relazioni:
    G.add_edge(p1, p2)

Disegnare la rete


import matplotlib.pyplot as plt
nx.draw(G, with_labels=True)
plt.show()

Degree


for nodo in G.nodes():
    print(nodo, G.degree(nodo))

Centralità

Un nodo centrale ha molte connessioni o occupa una posizione strategica nella rete.

Relazioni pesate


G.add_edge("Victor", "Creature", weight=5)

Spessore degli archi


larghezze = [G[u][v].get("weight", 1) for u, v in G.edges()]
nx.draw(G, with_labels=True, width=larghezze)

Rete diretta

In una rete diretta, la relazione ha una direzione: A scrive a B.


G = nx.DiGraph()

Limiti interpretativi

Una rete non è la realtà: è un modello costruito sulla base di criteri scelti.
