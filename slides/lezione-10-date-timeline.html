📅 Perché le date?

Le date permettono di trasformare testi storici e letterari in sequenze cronologiche.

Date numeriche


testo = "Frankenstein was published in 1818."

Regex


import re
date = re.findall(r"\d{4}", testo)
print(date)

Limite delle regex

Le regex trovano forme, non significati: Novecento non contiene cifre.

Date con spaCy


import spacy
nlp = spacy.load("en_core_web_sm")
doc = nlp("The novel became famous in the nineteenth century.")
for ent in doc.ents:
    if ent.label_ == "DATE":
        print(ent.text)

Espressioni temporali

  • 1818
  • January 1818
  • the nineteenth century
  • today
  • Novecento

Dal testo all’evento

Una timeline richiede almeno due informazioni: una data e una descrizione.

Lista di eventi


eventi = [
    {"Data": "1818-01-01", "Evento": "Frankenstein"},
    {"Data": "1831-01-01", "Evento": "Revised edition"}
]

DataFrame


import pandas as pd
df = pd.DataFrame(eventi)
print(df)

Convertire date


df["Data"] = pd.to_datetime(df["Data"])
print(df.dtypes)

Plotly


import plotly.express as px
fig = px.scatter(df, x="Data", y="Evento", text="Evento")
fig.show()

Categorie


eventi = [
 {"Data":"1818-01-01", "Evento":"Frankenstein", "Categoria":"Letteratura"},
 {"Data":"1859-01-01", "Evento":"Origin of Species", "Categoria":"Scienza"}
]

Timeline con categorie


df = pd.DataFrame(eventi)
df["Data"] = pd.to_datetime(df["Data"])
fig = px.scatter(df, x="Data", y="Categoria", text="Evento", color="Categoria")
fig.show()

Esportare HTML


fig.write_html("timeline_eventi.html")
print("File creato")

Interpretazione

La timeline mostra successioni, concentrazioni, vuoti e rapporti tra fenomeni storici e culturali.
