DEFINIZIONE MDN · CICLI1 min

Definizione · Che cos’è un ciclo?

Un ciclo (in inglese loop) è una struttura che permette di ripetere una serie di istruzioni, invece di riscriverle ogni volta.

In generale

La ripetizione prosegue finché si verificano le condizioni previste dal programma.

Nel nostro Python

for visita, uno alla volta, gli elementi di una sequenza.

Fonte: MDN — Glossario: Loop. Definizione riformulata in italiano; esempi adattati a Python.

CONCETTO · CICLI1 min

Che cos’è un’iterazione?

Una iterazione è una singola esecuzione delle istruzioni del ciclo.
nomi = ["Victor", "Walton", "Elizabeth"]

for nome in nomi:
    print(nome)

1ª iterazione: nome = "Victor"

2ª iterazione: nome = "Walton"

3ª iterazione: nome = "Elizabeth"

Quando finiscono gli elementi, il ciclo termina.

Fonte: Python Tutorial — for Statements. Definizione riformulata in italiano; esempi adattati a Python.

if, else e l’operatore in

DEFINIZIONE MDN · CONDIZIONI1 min

Definizione · Che cos’è una condizione?

Una condizione è una verifica che determina se eseguire un blocco di istruzioni oppure seguire un’altra strada.
parola = "Victor"

if parola == "Victor":
    print("Personaggio trovato")

Come ragiona Python?

La verifica parola == "Victor" restituisce True o False.

Se è True, esegue la stampa.

Fonte: MDN — Glossario: Conditional. Definizione riformulata in italiano; esempi adattati a Python.

DEFINIZIONE MDN · CONDIZIONI1 min

Flusso di controllo: non tutte le righe vengono eseguite

Il flusso di controllo è l’ordine in cui un programma esegue le istruzioni. if e for possono modificare questo ordine.
età = 19

if età >= 18:
    print("Maggiorenne")
else:
    print("Minorenne")

print("Controllo concluso")

Scelta: uno solo dei due blocchi if / else viene eseguito.

Poi: il programma prosegue con la riga finale.

Fonte: MDN — Glossario: Control flow. Definizione riformulata in italiano; esempi adattati a Python.

Dizionari

Associare ogni chiave a un valore

DEFINIZIONE MDN · STRUTTURE DATI1 min

Definizione · Che cos’è una struttura dati?

Una struttura dati è un modo di organizzare informazioni affinché possano essere memorizzate, recuperate e utilizzate in modo efficace.

Lista list

Raggruppa elementi in sequenza: ciascuno ha una posizione numerica.

["Victor", "Walton"]

Dizionario dict

Raggruppa associazioni chiave → valore.

{"Victor": 3, "Walton": 1}

Fonte: MDN — Glossario: Data structure. Definizione riformulata in italiano; esempi adattati a Python.

Specificità di list e dict: documentazione ufficiale Python.

CONFRONTO · LISTE / DIZIONARI2 min

Differenza fondamentale: lista e dizionario

Lista = successione di elementi

nomi = ["Victor", "Walton", "Victor"]
print(nomi[0])   # Victor
print(nomi[2])   # Victor
Si accede con un indice numerico. Il primo elemento ha indice 0. I valori possono ripetersi.

Dizionario = associazioni

frequenze = {"Victor": 2, "Walton": 1}
print(frequenze["Victor"])  # 2
Si accede tramite una chiave. Ogni chiave identifica un solo valore nel dizionario.

Fonte: Python Tutorial — Data Structures. Definizione riformulata in italiano; esempi adattati a Python.

RIEPILOGO VISIVO1 min

Confronto: quando scegliere lista o dizionario?

CaratteristicaLista listDizionario dict
Scrittura["Victor", "Walton"]{"Victor": 2, "Walton": 1}
AccessoIndice: nomi[0]Chiave: freq["Victor"]
OrganizzazioneSequenza di elementiCoppie chiave–valore
RipetizioniLo stesso valore può comparire più volteOgni chiave è unica
Quando è utile?Elenco di parole, nomi, frasiConteggi, attributi, informazioni associate
Attenzione: anche i dizionari Python moderni conservano l’ordine di inserimento. La differenza non è “ordinato / disordinato”, ma indice / chiave.

Fonte: Python Tutorial — Lists and Dictionaries. Definizione riformulata in italiano; esempi adattati a Python.

LISTE / DIZIONARI · ESEMPIO1 min

Cosa controlla l’operatore in?

Nella lista: cerca un elemento

nomi = ["Victor", "Walton"]
print("Victor" in nomi)  # True
print(2 in nomi)         # False

Nel dizionario: cerca una chiave

frequenze = {"Victor": 2, "Walton": 1}
print("Victor" in frequenze)  # True
print(2 in frequenze)         # False
Non confondere: 2 è un valore del dizionario, non una chiave. Per questo 2 in frequenze è falso.

Fonte: Python Tutorial — Dictionaries. Definizione riformulata in italiano; esempi adattati a Python.

FREQUENZE2 min

Attenzione alla punteggiatura!

testo = "Victor, Victor. victor"

FREQUENZE1 min

Pulizia minima: replace()

testo = "Victor, Victor. victor"
testo = testo.lower()
testo = testo.replace(",", "")
testo = testo.replace(".", "")
parole = testo.split()
print(parole)  # ["victor", "victor", "victor"]
È una pulizia didattica: su testi reali servono trattamenti più completi per segni, apostrofi e tokenizzazione.
