Che cos’è un algoritmo?

Una serie di passi per risolvere un problema.


Problema → Passi → Risultato

Il ciclo for


parole = ["Victor", "science", "creature"]

for parola in parole:
    print(parola)

range()

Genera una sequenza di numeri.


for i in range(5):
    print(i)

Condizione if

Permette di eseguire codice solo se una condizione è vera.


parola = "Victor"

if parola == "Victor":
    print("Personaggio trovato")

Operatore in

Controlla se qualcosa è contenuto in qualcosa.


testo = "Victor created the creature"

if "Victor" in testo:
    print("Trovato")

Ricerca in un testo


testo = "Victor met Walton"
nomi = ["Victor", "Elizabeth", "Walton"]

for nome in nomi:
    if nome in testo:
        print("Trovato:", nome)

Contare con una variabile


parole = ["Victor", "Victor", "Creature"]
contatore = 0

for parola in parole:
    if parola == "Victor":
        contatore = contatore + 1

print(contatore)

Dizionari

Un dizionario associa una chiave a un valore.


frequenze = {"Victor": 2, "Creature": 1}
print(frequenze)

Chiave e valore


"Victor" → 2
"Creature" → 1

Accedere a un valore


frequenze = {"Victor": 2, "Creature": 1}
print(frequenze["Victor"])

Aggiornare un valore


frequenze = {"Victor": 2}
frequenze["Victor"] = frequenze["Victor"] + 1
print(frequenze)

Costruire frequenze


parole = ["victor", "creature", "victor"]
frequenze = {}

for parola in parole:
    if parola in frequenze:
        frequenze[parola] += 1
    else:
        frequenze[parola] = 1

print(frequenze)

Perché un dizionario?

Perché permette di collegare ogni parola al suo numero di occorrenze.

Esercizio

📝 Esercizio 5

Costruire automaticamente un vocabolario di frequenze.

Soluzione

📝 Soluzione 5


testo = "Victor met Victor and the Creature"
parole = testo.lower().split()
frequenze = {}

for parola in parole:
    if parola in frequenze:
        frequenze[parola] += 1
    else:
        frequenze[parola] = 1

print(frequenze)

Mini progetto

Frequenza delle parole in una citazione.


testo = "Nel mezzo del cammin di nostra vita mezzo mezzo"
parole = testo.lower().split()
frequenze = {}

for parola in parole:
    if parola in frequenze:
        frequenze[parola] += 1
    else:
        frequenze[parola] = 1

print(frequenze)

Interpretazione

Le frequenze mostrano ciò che ricorre, ma non sostituiscono l’interpretazione critica.
