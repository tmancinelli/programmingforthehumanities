📌 Perché XML nelle DH?

XML permette di rappresentare testi strutturati: capitoli, paragrafi, versi, note, nomi, luoghi e varianti.

🧱 Documento strutturato

Un testo digitale non è solo una sequenza di parole: può contenere livelli di informazione espliciti.

🏷️ Tag

I tag indicano il ruolo di una parte del testo.


<p>Questo è un paragrafo.</p>

🔗 Attributi

Gli attributi aggiungono informazioni al tag.


<persName ref="https://www.wikidata.org/wiki/Q40909">Mary Shelley</persName>

🌳 Struttura ad albero

Un documento XML è gerarchico: un elemento può contenere altri elementi.

📚 Che cos’è TEI?

TEI è uno standard per codificare testi letterari, storici e documentari.

TEI nelle edizioni digitali

  • trascrizioni
  • apparati
  • metadati
  • nomi e luoghi
  • varianti

Esempio TEI minimo


<TEI>
  <text>
    <body>
      <p>Mary Shelley wrote Frankenstein.</p>
    </body>
  </text>
</TEI>

📦 Libreria ElementTree

Python include una libreria per leggere XML.


import xml.etree.ElementTree as ET

Caricare un file XML


import xml.etree.ElementTree as ET

tree = ET.parse("testo.xml")
root = tree.getroot()
print(root.tag)

XML come stringa


import xml.etree.ElementTree as ET

xml = """
<root><p>Frankenstein</p></root>
"""
root = ET.fromstring(xml)
print(root.tag)

Trovare elementi


paragrafi = root.findall(".//p")

for p in paragrafi:
    print(p.text)

Estrarre tutto il testo


for p in root.findall(".//p"):
    testo = "".join(p.itertext())
    print(testo)

Versi poetici


for verso in root.findall(".//l"):
    print("".join(verso.itertext()))

Nomi di persona


for nome in root.findall(".//persName"):
    print(nome.text)

Luoghi


for luogo in root.findall(".//placeName"):
    print(luogo.text)

Attributi con .get()


for nome in root.findall(".//persName"):
    print(nome.text, nome.get("ref"))

Namespace TEI

Molti file TEI usano namespace: servono dizionari di prefissi.


ns = {"tei": "http://www.tei-c.org/ns/1.0"}
paragrafi = root.findall(".//tei:p", ns)

Esempio con namespace


for p in root.findall(".//tei:p", ns):
    print("".join(p.itertext()).strip())

Errore comune

Se findall() non trova nulla, spesso il problema è il namespace.
