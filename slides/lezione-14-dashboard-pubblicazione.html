🧩 Perché una dashboard?

Una dashboard raccoglie in un unico spazio risultati diversi: grafici, mappe, timeline, testi.

Output del corso

  • grafici Plotly
  • mappe Folium
  • wordcloud.png
  • network.png
  • tabelle CSV

Organizzare cartelle


progetto/
  dati/
  immagini/
  html/
  script/

Salvare Plotly


fig.write_html("html/timeline.html")

Salvare Folium


mappa.save("html/mappa.html")

Salvare immagine


plt.savefig("immagini/network.png", dpi=150)

HTML base


<!DOCTYPE html>
<html>
<head><meta charset="utf-8"><title>Dashboard DH</title></head>
<body>
<h1>Dashboard DH</h1>
</body>
</html>

Inserire immagine


<img src="immagini/wordcloud.png" alt="Word Cloud">

Iframe per HTML esterni


<iframe src="html/mappa.html" width="100%" height="500"></iframe>
