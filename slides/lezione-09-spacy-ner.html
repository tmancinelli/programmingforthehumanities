📌 Che cos’è spaCy?

spaCy è una libreria NLP per analizzare testi e riconoscere strutture linguistiche.

Installazione


pip install spacy
python -m spacy download en_core_web_sm

Caricare il modello


import spacy
nlp = spacy.load("en_core_web_sm")

Testo di esempio


testo = """
Mary Shelley published Frankenstein in London in 1818.
Victor Frankenstein studied in Ingolstadt.
"""

Analisi


doc = nlp(testo)

Entità nominate

Le entità nominate sono elementi riconoscibili: persone, luoghi, date, organizzazioni.

Stampare entità


for ent in doc.ents:
    print(ent.text, ent.label_)

PERSON

PERSON indica nomi di persona.


for ent in doc.ents:
    if ent.label_ == "PERSON":
        print(ent.text)

GPE e LOC

GPE indica entità geopolitiche; LOC luoghi naturali o geografici.

DATE


for ent in doc.ents:
    if ent.label_ == "DATE":
        print(ent.text)

ORG

ORG riconosce organizzazioni, istituzioni, università.

Modelli linguistici

  • en_core_web_sm
  • en_core_web_md
  • en_core_web_lg
  • it_core_news_sm
  • de_core_news_sm

Errore comune E050

Se spaCy non trova il modello, bisogna scaricarlo con python -m spacy download ....

Contare entità


from collections import Counter
persone = [ent.text for ent in doc.ents if ent.label_ == "PERSON"]
print(Counter(persone))

Tabella con pandas


import pandas as pd
from collections import Counter
conteggio = Counter(persone).most_common()
df = pd.DataFrame(conteggio, columns=["Nome", "Occorrenze"])
print(df)

NER non è perfetto

Il modello può sbagliare: confondere nomi comuni con luoghi, non riconoscere nomi storici o interpretare male contesti ambigui.
