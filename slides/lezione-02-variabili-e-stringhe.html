Che cos’è una variabile?

Una variabile è un nome che associamo a un valore.


titolo = "Frankenstein"

Assegnazione

Il simbolo = assegna un valore a una variabile.


autore = "Mary Shelley"
anno = 1818

Stampare variabili


titolo = "Frankenstein"
print(titolo)

Tipi di dato

  • Stringhe: testo
  • Interi: numeri senza virgola
  • Decimali: numeri con virgola
  • Booleani: vero/falso

Stringhe

Una stringa è una sequenza di caratteri.


frase = "Victor studied science"
print(frase)

Numeri


anno = 1818
pagine = 280
print(anno)
print(pagine)

Concatenazione

Unire stringhe con +.


nome = "Mary"
cognome = "Shelley"
print(nome + " " + cognome)

Attenzione ai tipi

Testo e numeri non si uniscono direttamente.


titolo = "Frankenstein"
anno = 1818
print(titolo, anno)

La funzione len()

len() conta la lunghezza di una stringa.


testo = "Frankenstein"
print(len(testo))

Maiuscole e minuscole


testo = "Frankenstein"
print(testo.upper())
print(testo.lower())

Sostituire parole


frase = "Victor loves science"
nuova = frase.replace("science", "knowledge")
print(nuova)

Dividere un testo

split() trasforma una stringa in una lista di parole.


frase = "Victor studied science"
parole = frase.split()
print(parole)

Stringhe multilinea


testo = """
Victor writes.
Elizabeth listens.
"""
print(testo)

Metadati umanistici

Titolo, autore, anno e genere possono essere rappresentati con variabili.

Esempio DH


titolo = "Frankenstein"
autrice = "Mary Shelley"
anno = 1818
print(titolo, autrice, anno)
