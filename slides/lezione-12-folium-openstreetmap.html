🗺️ Mappe nelle Digital Humanities

Le mappe permettono di visualizzare la dimensione spaziale di testi, archivi e fenomeni culturali.

OpenStreetMap

OpenStreetMap è una base cartografica aperta usata da Folium e Leaflet.

Folium

Folium è una libreria Python che crea mappe interattive in HTML.

Installazione


pip install folium geopy

Creare una mappa


import folium
mappa = folium.Map(location=[51.1657, 10.4515], zoom_start=5)
mappa.save("mappa.html")

Coordinate

Ogni luogo può essere rappresentato da latitudine e longitudine.

Aggiungere un marker


folium.Marker(
    location=[52.5200, 13.4050],
    popup="Berlin"
).add_to(mappa)

Tooltip


folium.Marker(
    [48.8566, 2.3522],
    popup="Paris",
    tooltip="Paris"
).add_to(mappa)

Lista di luoghi


luoghi = [
    ("Berlin", 52.5200, 13.4050),
    ("Paris", 48.8566, 2.3522),
    ("London", 51.5072, -0.1276)
]

Ciclo sui luoghi


for nome, lat, lon in luoghi:
    folium.Marker([lat, lon], popup=nome).add_to(mappa)

Geocoding

Il geocoding trasforma un nome di luogo in coordinate.

Geopy


from geopy.geocoders import Nominatim
geolocator = Nominatim(user_agent="dh_map")
location = geolocator.geocode("Berlin")
print(location.latitude, location.longitude)

Occorrenze nei popup


popup = "Berlin<br>Occorrenze: 5"
folium.Marker([52.52, 13.40], popup=popup).add_to(mappa)

Salvare HTML


mappa.save("mappa_luoghi.html")
print("Mappa creata")

Attenzione agli errori

Il geocoder può confondere luoghi, persone e parole ambigue: serve controllo umano.
