Che cos’è Python? La definizione di MDN

Python è un linguaggio di programmazione di alto livello, di uso generale e multiparadigma.

Alto livello

Ci permette di descrivere operazioni senza gestire direttamente tutti i dettagli dell’hardware.

Uso generale

Può essere impiegato per applicazioni diverse: analisi di dati, automazione, siti e studi testuali.

Multiparadigma

Permette diversi modi di organizzare programmi: ad esempio, istruzioni in sequenza e programmazione a oggetti.

Dal linguaggio al nostro programma

Programma

Un insieme di istruzioni che Python può eseguire.

Istruzione

Un’operazione richiesta al programma: assegnare un valore, chiamare una funzione, stampare un risultato.

Dato

Un valore sul quale lavoriamo: testo, numero, lista.

Variabile

Un nome associato a un oggetto, che possiamo riutilizzare nel programma.

frase = "Victor Frankenstein studia la natura"  # Assegno una stringa a un nome
print(frase)                                   # Chiedo a Python di mostrarla
# Questa riga è un commento: non viene eseguita

Che cos’è una funzione?

Una funzione esegue un’operazione. Può ricevere degli argomenti fra parentesi e può restituire un risultato.
testo = "Frankenstein"   # Creo una variabile
print(testo)              # print() mostra un valore
print(len(testo))         # len() calcola la lunghezza
In Python print() e len() sono funzioni integrate: già disponibili, senza importare librerie.

Definizioni da ricordare: chiamata, argomento, risultato

Chiamata

Usare una funzione scrivendo il suo nome e le parentesi: len(...).

Argomento

Il valore passato alla funzione: in len(frase) è frase.

Valore restituito

Il risultato prodotto: len(frase) restituisce un numero.

frase = "Victor Frankenstein studia la natura" # Creo una variabile
numero = len(frase)                           # Passo la stringa a len(): ottengo 36
print(numero)                                 # Passo 36 a print(): lo visualizzo
# print() serve a mostrare un risultato; non è il conteggio stesso
Domanda alla classe: in print(len(frase)), quale funzione viene eseguita per prima? len(): il suo risultato diventa l’argomento di print().
Sottolineare differenza fra calcolare/restituire e visualizzare. Fonte: manuale Python, Built-in functions.

Funzioni integrate: tre esempi

print(x)

Mostra x a schermo.

len(x)

Restituisce quanti elementi contiene x.

type(x)

Restituisce il tipo del dato x.

frase = "Victor"                 # Stringa di testo
print(frase)                      # Visualizza "Victor"
print(len(frase))                 # Visualizza 6
print(type(frase))                # Visualizza <class 'str'>

Che cos’è un metodo?

Un metodo è una funzione associata a un oggetto. Lo richiamiamo dopo un punto: oggetto.metodo().
frase = "VICTOR"          # Creo una stringa
minuscolo = frase.lower() # Chiamo un metodo della stringa
print(minuscolo)          # Stampo il risultato
OUTPUT ATTESO victor
Il punto . è importante: stiamo chiedendo alla stringa di svolgere un’operazione.

Funzione o metodo? Confronto

Funzione integrata

len(frase)
print(frase)

L’oggetto è passato come argomento.

Metodo

frase.lower()
frase.split()

Il metodo è richiamato sull’oggetto.

Non scriviamo frase.len() né lower(frase) con i soli strumenti presentati oggi.

Glossario essenziale: oggetto, tipo, metodo

Oggetto

Un valore gestito da Python. Ogni oggetto ha un tipo, che determina le operazioni disponibili.

Tipo

str per le stringhe, list per le liste, int per i numeri interi.

Metodo

Una funzione associata a un tipo di oggetto, richiamata con la notazione oggetto.metodo().

Perché è importante?

frase.lower() funziona per una stringa; opere.append(...) per una lista.

frase = "VICTOR"        # Il tipo di frase è str
opere = ["Frankenstein"] # Il tipo di opere è list
print(type(frase))       # Visualizza <class 'str'>
print(type(opere))       # Visualizza <class 'list'>
print(frase.lower())     # Metodo della stringa: 'victor'
opere.append("Dracula")  # Metodo della lista: aggiunge un titolo
print(opere)             # Visualizza entrambe le opere

Per approfondire: Python Docs · Built-in Types.

Perché ci sono le parentesi tonde?

Senza parentesi

frase.lower

Indica il metodo, ma non lo esegue.

Con parentesi

frase.lower()

Esegue il metodo e restituisce una stringa.

frase = "VICTOR"
print(frase.lower()) # Le parentesi () eseguono il metodo
print e print() non sono intercambiabili: senza parentesi non stiamo chiamando la funzione.

Il segno = non è una definizione di uguaglianza

= è un’assegnazione: memorizza nella variabile il valore che si trova a destra.
frase = "Victor"            # Associo una stringa al nome frase
frase = frase + " studia"  # Calcolo una nuova stringa e la assegno
print(frase)               # Uso il valore aggiornato
OUTPUT ATTESO Victor studia
Lo stesso nome di variabile può essere riutilizzato per conservare un nuovo valore.

Passo 1: print(frase)

frase = "Victor Frankenstein studia la natura"
# Salvo una stringa nella variabile chiamata frase

print(frase)
# print() mostra a schermo il contenuto della variabile
OUTPUT ATTESO Victor Frankenstein studia la natura
La funzione print() serve a visualizzare, non a trasformare il testo.

Passo 2: frase.lower()

frase = "Victor Frankenstein studia la natura"
# Creo la stringa, con le maiuscole presenti nel testo

print(frase.lower())
# lower() restituisce una nuova stringa in minuscolo
# print() visualizza la nuova stringa
OUTPUT ATTESO victor frankenstein studia la natura
Usare il minuscolo aiuta a trattare Victor e victor nello stesso modo, in una prima analisi testuale.

lower() modifica la variabile?

frase = "VICTOR"         # Testo originale
print(frase.lower())      # Stampo la versione in minuscolo
print(frase)              # Stampo ancora il testo originale
OUTPUT ATTESO victor VICTOR
Le stringhe sono immutabili: lower() crea un nuovo valore, non riscrive il testo di partenza.

Come conservare il risultato di lower()

frase = "VICTOR"            # Creo una stringa
frase = frase.lower()      # Riassegno il risultato alla variabile
print(frase)               # Ora frase contiene "victor"
OUTPUT ATTESO victor
Qui il valore associato a frase cambia, perché lo abbiamo riassegnato esplicitamente.

Passo 3: len(frase)

frase = "Victor Frankenstein studia la natura"
# len() riceve una stringa e conta i suoi caratteri

numero_caratteri = len(frase)
# Salvo il risultato numerico in una variabile

print(numero_caratteri)
# Visualizzo il numero ottenuto
OUTPUT ATTESO 36
Gli spazi sono caratteri! In questo esempio si contano anche i quattro spazi fra le cinque parole.

Che cosa conta davvero len()?

Consideriamo una stringa molto corta:

testo = "a b"           # Una lettera, uno spazio, una lettera
print(len(testo))       # Conta tutti e tre i caratteri
OUTPUT ATTESO 3
aindice 0
␣indice 1
bindice 2
Qui ␣ indica lo spazio: è presente nella stringa anche se non lo vediamo come una lettera.

len() non significa sempre “numero di lettere”

Con una stringa

testo = "a b"      # 3 caratteri
print(len(testo))  # 3

Con una lista

parole = ["a", "b"]  # 2 elementi
print(len(parole))   # 2
len() è la stessa funzione, ma il risultato dipende dal tipo di oggetto che riceve.

Passo 4: frase.split()

frase = "Victor Frankenstein studia la natura"
# split() separa la stringa in parole negli spazi

parole = frase.split()
# Il risultato non è più una stringa: è una lista

print(parole)
# Stampo la lista ottenuta
OUTPUT ATTESO ['Victor', 'Frankenstein', 'studia', 'la', 'natura']
In questo primo caso usiamo split() senza argomenti: separa secondo gli spazi bianchi.

Passo 5: len(frase.split())

frase = "Victor Frankenstein studia la natura"
# Prima split() separa la stringa in parole
# Poi len() conta gli elementi della lista ottenuta

print(len(frase.split()))

Il codice è annidato: la parte interna frase.split() viene valutata prima di len(...).

split(): cosa succede con più spazi?

testo = "Victor   studia  la natura"
# Ci sono 3 spazi dopo Victor e 2 dopo studia

parole = testo.split()   # Separa sugli spazi bianchi
print(parole)            # Gli spazi multipli non generano vuoti
print(len(parole))       # Il numero di parole resta 4
OUTPUT ATTESO ['Victor', 'studia', 'la', 'natura'] 4
Con split() senza argomenti, Python tratta sequenze di spazi, tabulazioni e a capo come separatori.

split() e la punteggiatura

testo = "Victor, studia la natura."
# La punteggiatura è ancora attaccata alle parole

parole = testo.split()
print(parole)
OUTPUT ATTESO ['Victor,', 'studia', 'la', 'natura.']
Per una vera analisi linguistica split() è un primo passo, non un tokenizzatore completo. La punteggiatura andrà gestita in seguito.

Quale differenza fra questi due risultati?

testo = "Victor Victor victor"
# Confronto il testo originale con quello normalizzato

print(testo.split())              # Le maiuscole restano
print(testo.lower().split())      # Converto e poi separo
OUTPUT ATTESO ['Victor', 'Victor', 'victor'] ['victor', 'victor', 'victor']
I metodi possono essere concatenati: lower() produce una stringa su cui possiamo applicare split().

Come leggere una documentazione tecnica

Quando incontrate una funzione o un metodo, cercate quattro informazioni:

  1. Che cos’è? Una funzione integrata o un metodo di un tipo?
  2. Quali argomenti accetta? Che cosa mettiamo tra parentesi?
  3. Che cosa restituisce? Una stringa, una lista, un numero oppure None?
  4. Modifica l’oggetto originale? Confrontate lower() e append().

str.lower()

Restituisce una nuova stringa in minuscolo; la stringa originale rimane invariata.

str.split()

Restituisce una lista di stringhe; senza argomenti usa gli spazi bianchi come separatori.

Perché ci servono le liste?

Una lista è una collezione ordinata e modificabile di elementi. Si scrive con parentesi quadre [ ].
personaggi = ["Victor", "Elizabeth", "Walton"]
# Tre nomi conservati insieme in una lista

print(personaggi) # Visualizzo l’intera lista
OUTPUT ATTESO ['Victor', 'Elizabeth', 'Walton']
Una lista è utile per rappresentare personaggi, opere, luoghi, parole o altri dati estratti dai testi.

Una stringa non è una lista

Stringa str

opera = "Frankenstein"
# Un singolo dato testuale
print(type(opera))

Lista list

opere = ["Frankenstein", "Dracula"]
# Una collezione di dati
print(type(opere))
Le virgolette indicano testo. Le parentesi quadre indicano una lista.

Una lista ha elementi e posizioni

Victorindice 0
Elizabethindice 1
Waltonindice 2
personaggi = ["Victor", "Elizabeth", "Walton"]
# Gli indici iniziano da zero, non da uno

print(personaggi[0]) # Primo elemento: Victor
print(personaggi[1]) # Secondo elemento: Elizabeth
Chiedere: perché il terzo elemento ha indice 2? Perché contiamo da zero.

Gli indici partono da zero

personaggi = ["Victor", "Elizabeth", "Walton"]
# 0 = prima posizione
# 1 = seconda posizione
# 2 = terza posizione

print(personaggi[0]) # Victor
print(personaggi[2]) # Walton
OUTPUT ATTESO Victor Walton
L’indice identifica la posizione dell’elemento, non il suo valore.

Per accedere all’ultimo elemento: [-1]

personaggi = ["Victor", "Elizabeth", "Walton"]
# -1 indica l’ultimo elemento della lista

print(personaggi[-1]) # Walton
OUTPUT ATTESO Walton
Un indice negativo conta a partire dalla fine. È comodo anche quando non conosciamo la lunghezza della lista.

La stessa len() su una lista

personaggi = ["Victor", "Elizabeth", "Walton"]
# len() su una lista conta i suoi elementi

print(len(personaggi)) # 3 elementi

testo = "Victor"
# len() su una stringa conta i caratteri
print(len(testo)) # 6 caratteri
OUTPUT ATTESO 3 6
Chiarimento centrale: len() non “conta sempre le parole”. Conta gli elementi contenuti nell’oggetto ricevuto.

Modificare un elemento della lista

personaggi = ["Victor", "Elizabeth", "Walton"]
# Le liste possono cambiare dopo la loro creazione

personaggi[1] = "Creature" # Sostituisco il secondo elemento
print(personaggi)           # Visualizzo la nuova lista
OUTPUT ATTESO ['Victor', 'Creature', 'Walton']
Diversamente dalle stringhe, le liste sono modificabili.

Aggiungere un elemento con append()

personaggi = ["Victor", "Elizabeth"]
# Creo una lista con due elementi

personaggi.append("Walton")
# append() aggiunge un nuovo elemento alla fine

print(personaggi) # La lista ora contiene tre elementi
OUTPUT ATTESO ['Victor', 'Elizabeth', 'Walton']
append() è un metodo delle liste, così come lower() è un metodo delle stringhe.

Due metodi, due comportamenti

lower() · stringhe

testo = "VICTOR"
nuovo = testo.lower() # Nuova stringa
print(testo)          # VICTOR
print(nuovo)          # victor

append() · liste

nomi = ["Victor"]
nomi.append("Walton") # Modifica la lista
print(nomi)            # Due nomi
Non tutti i metodi funzionano allo stesso modo: alcuni restituiscono un nuovo oggetto, altri modificano quello esistente.

Attenzione: append() non restituisce la lista

opere = ["Frankenstein"]
# Aggiungo un nuovo titolo modificando la lista originale
risultato = opere.append("Dracula")

print(opere)     # Lista aggiornata
print(risultato) # None: append non restituisce la lista
OUTPUT ATTESO ['Frankenstein', 'Dracula'] None
Meglio scrivere opere.append("Dracula") e poi print(opere).

Errore comune: indice inesistente

Una lista con tre elementi ha indici 0, 1, 2.

personaggi = ["Victor", "Elizabeth", "Walton"]
print(personaggi[3])  # IndexError!
personaggi[3] chiede il quarto elemento, che non esiste. L’errore si chiama IndexError.

Il collegamento con split()

frase = "Victor studia la natura"
# split() ci consente di ottenere una lista dal testo

parole = frase.split()
# Parole: ["Victor", "studia", "la", "natura"]

print(parole[0])     # Prima parola
print(parole[-1])    # Ultima parola
print(len(parole))   # Numero di parole
OUTPUT ATTESO Victor natura 4
Questa è la transizione cruciale: testo → lista di parole.

Testo narrativo

Una storia comprende personaggi, luoghi, opere, eventi...

Dati in Python

personaggi = ["Victor", "Elizabeth"]
luoghi = ["Geneva", "Ingolstadt"]
# Organizzo informazioni in collezioni
Una lista è già un primo modo di selezionare e strutturare informazioni, ma non descrive ancora le relazioni fra le entità.

Dalla lista al ciclo for

Un ciclo for permette di eseguire lo stesso blocco di istruzioni per ogni elemento di una collezione.
personaggi = ["Victor", "Elizabeth", "Walton"]
# Per ogni nome contenuto nella lista...

for nome in personaggi:
    print(nome) # ...stampo quel nome
OUTPUT ATTESO Victor Elizabeth Walton

Come leggere un ciclo ad alta voce

for nome in personaggi:

«Per ogni nome nella lista personaggi»

print(nome)

«stampa il nome corrente»

nome è una variabile temporanea: assume uno dopo l’altro i valori presenti nella lista.

Il ciclo passo dopo passo

1ª iterazione

nome = "Victor"

Stampa Victor

2ª iterazione

nome = "Elizabeth"

Stampa Elizabeth

3ª iterazione

nome = "Walton"

Stampa Walton

Il ciclo esegue le istruzioni interne una volta per ogni elemento.

L’indentazione in Python non è decorativa

Corretto

nomi = ["Victor", "Walton"]
for nome in nomi:
    print(nome) # 4 spazi all’inizio

Errato

nomi = ["Victor", "Walton"]
for nome in nomi:
print(nome) # manca l’indentazione
I quattro spazi segnalano quali istruzioni appartengono al ciclo. La versione errata produce IndentationError.

Il ruolo dei due punti :

parole = ["Victor", "studia", "natura"]
# I due punti aprono il blocco del for

for parola in parole:
    print(parola) # Istruzione ripetuta a ogni iterazione

print("Fine") # Fuori dal ciclo: eseguita una sola volta
OUTPUT ATTESO Victor studia natura Fine
Il rientro del codice determina cosa viene ripetuto e cosa viene eseguito soltanto alla fine.

for e split() insieme

frase = "Victor Frankenstein studia la natura"
# Da una stringa ottengo una lista di parole
parole = frase.split()

for parola in parole:
    # Ogni iterazione prende la parola successiva
    print(parola)
OUTPUT ATTESO Victor Frankenstein studia la natura
Una tecnica di base dell’analisi testuale: leggere una parola alla volta.

Possiamo iterare direttamente sul risultato di split()

frase = "Victor studia la natura"
# Creo la lista con split() e la percorro subito

for parola in frase.split():
    print(parola) # Una parola per riga
OUTPUT ATTESO Victor studia la natura
La versione con parole = frase.split() è più leggibile quando il programma diventa lungo.

Se ciclo su una stringa, cosa succede?

testo = "Roma"
# Una stringa è una sequenza di caratteri

for carattere in testo:
    print(carattere) # Una lettera per riga
OUTPUT ATTESO R o m a
Un ciclo su una stringa percorre i caratteri; su una lista di parole percorre le parole.

Differenza: prima e dopo split()

Senza split()

testo = "a b"
for x in testo:
    print(x) # Anche lo spazio

Con split()

testo = "a b"
for x in testo.split():
    print(x) # Solo 2 parole
La domanda da porsi è sempre: quale tipo di oggetto sto iterando?

Dal ciclo alla numerazione: range()

for numero in range(4):
    # range(4) produce 0, 1, 2, 3
    print(numero)
OUTPUT ATTESO 0 1 2 3
range(4) non include il numero 4. Lo useremo ancora quando lavoreremo con cicli e condizioni.
