🤖 Che cos’è il NLP?

Il Natural Language Processing studia come trattare automaticamente il linguaggio umano con il computer.

NLP nelle Digital Humanities

  • analisi di testi letterari
  • studio di corpora
  • estrazione di informazioni
  • confronto tra testi

Testo di partenza


testo = """
Victor loved science. The creature wanted love.
Science changed Victor forever.
"""

Tokenizzazione semplice


parole = testo.split()
print(parole)

Minuscole


testo = testo.lower()
print(testo)

Pulizia della punteggiatura


parola = "science."
parola = parola.strip(".,;:!?()[]"'")
print(parola)

Token puliti


tokens = []
for parola in testo.lower().split():
    parola = parola.strip(".,;:!?()[]"'")
    if parola:
        tokens.append(parola)
print(tokens)

Stopwords

Le stopwords sono parole molto frequenti ma poco informative: the, and, of.

Rimuovere stopwords


stopwords = ["the", "and", "of", "a"]
filtrate = []
for token in tokens:
    if token not in stopwords:
        filtrate.append(token)
print(filtrate)

Frequenze con dizionario


frequenze = {}
for token in filtrate:
    if token in frequenze:
        frequenze[token] += 1
    else:
        frequenze[token] = 1
print(frequenze)

Counter


from collections import Counter
conteggio = Counter(filtrate)
print(conteggio.most_common(10))

Interpretare le frequenze

Una parola frequente non è automaticamente una parola importante: serve sempre interpretazione critica.

Corpus

Un corpus è una raccolta di testi usata per l’analisi.

Confrontare testi

Possiamo confrontare frequenze tra capitoli, autori, epoche o generi.

Limiti del metodo

  • punteggiatura
  • varianti grafiche
  • maiuscole
  • forme flesse

NLP e filologia

La preparazione del testo è una scelta interpretativa, non solo tecnica.
